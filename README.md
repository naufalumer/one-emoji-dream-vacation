One emoji for the dream vacation: not any beach, not any mountain, one mountain. Dawn over Mount Fuji, the trip you picture when someone says "one day".

> 🗻

## Run it

```sh
python3 main.py
```

It writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it.
